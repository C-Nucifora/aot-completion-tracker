# Qt6 conversion implementation plan

Goal: Convert the completion tracker into an offline native Qt6 application while preserving its features.

Approved scope: native PySide6 widgets; save/snapshot/tracker import; searchable lists; corrections; farming plans; run logs; JSON, CSV and raw exports; application-menu launcher. Original saves remain read-only. Browser artifacts remain available.

Architecture: reuse save_reader.py and catalog.json. Port planner.js and app.js profile/mission logic into tracker_core.py. Build desktop_app.py using Qt Widgets, with no web view. Use XDG application data for atomic local persistence and preserve the existing tracker JSON format. PySide6 Essentials is the only new runtime dependency.

- [x] Port crafting, allocation, mission estimates, validation and profile corrections. Compare Python outputs with the existing JavaScript implementation on real snapshots; reject malformed JSON and preserve fortified inventory.
- [x] Build native tables, plan controls, run editor, import/export and slot selection. Add uv metadata, a launcher and a user-menu installer. Preserve raw offsets and expose uncertainty in drop rates and ETA.
- [x] Run syntax and parity checks, exercise import/edit/export/reload with current saves without altering them, inspect the app in a private desktop, review the diff, install the launcher and commit locally.

Verification uses temporary scripts and private fixtures outside the repository. No new test suite is added, per realistic-commits. Work stays in the clean existing checkout on a feature branch; no push is authorized.
