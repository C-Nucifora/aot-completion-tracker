# Dark desktop refresh scope

The user requested a dark mode, full interface refresh and installation as a Linux app, then approved charcoal surfaces, warm gold accents, clearer tables and a persistent light/dark switch.

Keep all existing save-reading, planning, corrections, run logs and exports. Keep the source saves read-only and preserve existing tracker JSON/session storage. Linux is the priority; use the same refreshed native code in the existing Windows portable bundle.

Use an operating interface rather than a dashboard. Put navigation in a left rail; keep save actions and section context at the top; use tables for long data lists. Bring missing material sources forward when rates are unknown. Make technical evidence available without making it the first thing a player must read.

The installer places a separate app/runtime outside Downloads and adds an application-menu entry plus a command launcher. It never stops the current user window or alters personal tracker data.
