# Native desktop interface

The Qt6 app preserves the completion notebook's warm paper and dark green identity. This is an operation-focused desktop tool for checking progress between game sessions.

Use native Qt Widgets and a consistent Fusion palette. Navigation stays in a left list with 38 px rows; the right workspace holds searchable, sortable tables. Keep File actions in the toolbar and menu, use ordinary native dialogs for opening/exporting files, and support keyboard shortcuts and visible focus. Numeric columns align right; checkboxes show acquisition and completion states. Long table content is available in tooltips and horizontal scrolling.

The farming view separates mission routes, shopping shortages, crafting order and body-part sources in native tabs. Unknown rates and missing full-completion estimates remain explicit. No web view, decorative imagery, animated dashboard or network service is needed.

Verified on a private Linux desktop at 1280×720. Navigation overlap found in the first inspection was fixed with explicit item heights. A second inspection confirmed the plan layout. The same source is packaged for Windows; platform execution evidence is recorded separately.
